# Contributing to A Friend When There Is None

Thank you for being here. Your contribution matters.

## Who We're Looking For

We especially welcome:

- **Trauma-informed designers** — Help us build interfaces that are safe, accessible, and gentle for people in crisis
- **Backend developers** — Python, PostgreSQL, DevOps, security expertise
- **Shortcut developers** — Apple Shortcuts specialists who understand automation at scale
- **Community builders** — Help us grow channels authentically and safely
- **Trans & formerly incarcerated advisors** — Your lived experience is invaluable; we need your perspective on what actually works
- **Mental health professionals** — Help us understand how to support people safely

## How to Contribute

### Report Issues
Found a bug? Security concern? Privacy issue?
- Open an issue with as much detail as possible
- For security issues, email directly (don't post publicly)

### Suggest Features
- Open a discussion first (we want to talk through it)
- Explain the use case — who needs this and why?
- Be specific about how it helps people in crisis

### Code Contributions
1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Write tests (we use pytest)
5. Submit a PR with clear description

### Documentation
- Typos? Confusing sections? Fix it.
- Examples? Add them.
- Process unclear? Document it.

## Our Principles

- **People first** — Every decision asks: "Does this help people in crisis?"
- **Privacy sacred** — We will never compromise on data security
- **Trauma-informed** — We understand what safe looks like
- **Accessible** — Works for people with limited tech skills, bandwidth, resources
- **Transparent** — You know what we're doing and why

## Code of Conduct

Be kind. Be real. Be here for the mission.

We don't tolerate:
- Discrimination (any form)
- Breach of privacy (any scope)
- Dismissal of lived experience
- Exploitation

## Getting Help

- **Questions?** Open a discussion
- **Stuck?** Reach out — we'll help
- **Want to talk first?** Email or open an issue

---

**Every contribution moves us closer to a world where people in crisis have sanctuary.**

Thank you for being part of this.
